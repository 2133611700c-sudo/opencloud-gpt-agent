# AGENTS

## Mandatory session start
1. Read `ops/agent-control/STATUS.md` from the first line before selecting or executing work.
2. Treat its `SUPERVISOR BOARD — READ FIRST` section as the current orientation board.
3. Execute only its `One next action` in a small evidence-producing step unless the supervisor updates the board.
4. After verification, update the board before starting another action.

## Operating mode
- ChatGPT is supervisor.
- OpenClaw Cloud Agent is external executor.
- Max autonomy for execution inside repository scope.

## Rights
- Read all repository files.
- Run workflows and scripts.
- Create evidence reports.
- Prepare patches and PR-ready changes.

## Required discipline
- Evidence-first completion.
- Report only verified outcomes.
- Use `PASS | FAIL | BLOCKED`.
